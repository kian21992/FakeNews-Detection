# Ethics Statement

## Overview
This project aims to help users evaluate the credibility of news content. Because fake news detection can affect trust, reputation, and public opinion, the system must be used responsibly.

## Bias and Fairness
The model may reflect biases from its training data, feature design, or domain reputation lists. Some news sources may be unfairly favored or penalized. This means the system may not treat all publishers equally.

## Risk of Misclassification
The model can make mistakes. It may label true content as fake, or fake content as true. This is especially possible for:
- satire
- opinion pieces
- incomplete articles
- breaking news
- articles without enough context

## Responsible Use
This system should be used only as a support tool. Its predictions should not be treated as final proof. Human review is still necessary, especially for sensitive or high-impact topics.

## Transparency
Users should be informed that the system uses automated methods and may be uncertain. Predictions should be explained with supporting signals where possible, such as model confidence, subjectivity, or source reputation.

## Privacy
If user feedback or article data is stored, it should be handled carefully and only for project purposes. Sensitive personal data should not be collected unnecessarily.

## Harm Prevention
This tool must not be used to harass, defame, or unfairly target individuals, organizations, or media outlets. The project should aim to reduce misinformation without causing additional harm.

## Human Oversight
A human should always have the final say when interpreting results. The model is an assistant, not an authority.

## Future Improvements
To improve ethical use, future work should include:
- more balanced training data
- clearer explanations for predictions
- stronger evaluation across different article types
- regular review of bias and error patterns
